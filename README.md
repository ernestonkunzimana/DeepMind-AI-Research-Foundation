## Keep Learning: AI Research Foundation Path

If your goal is to keep learning and get more value from AI research foundations, use this simple progression:

1. **Math & Statistics Basics**
   - Linear algebra (vectors, matrices, eigenvalues)
   - Probability, distributions, and Bayes rule
   - Calculus basics for optimization

2. **Core Machine Learning**
   - Supervised vs. unsupervised learning
   - Training, validation, overfitting, regularization
   - Evaluation metrics and error analysis

3. **Deep Learning Fundamentals**
   - Neural networks and backpropagation
   - CNNs, RNNs/Transformers, embeddings
   - Optimization (SGD/Adam), learning rates, batch normalization

4. **Reinforcement Learning Foundations**
   - Agents, environments, rewards, policies
   - Value functions and Q-learning
   - Policy gradients and model-based RL basics

5. **Research Skills**
   - Read one paper weekly and summarize key ideas
   - Reproduce one small experiment monthly
   - Track assumptions, limitations, and open questions

## Practical Weekly Learning Loop

- **Day 1-2:** Learn one concept deeply  
- **Day 3-4:** Implement a minimal example  
- **Day 5:** Evaluate results and write short notes  
- **Day 6-7:** Review, refine, and connect to a research paper

## Suggested Output for Every Topic

- A short explanation in your own words
- A small code experiment
- A result snapshot (metric, chart, or observation)
- One improvement idea for next iteration
